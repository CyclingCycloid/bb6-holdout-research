# BMO 1 形式化归约：图灵机 ⟺ 双计数器递推（机器可验证版）

**机器**: BMO 1 = `1RB1RE_1LC0RA_0RD1LB_---1RC_1LF1RE_0LB0LE`
（6 状态 A–F，2 符号；全 0 纸带，头在原点 0，起始状态 A；停机 = 状态 D 读到 0 时触发未定义转移 `---`）

**约定**: 转移记号 `XYZ` = 写符号 X，移动方向 Y（L/R），转移到状态 Z。

| 状态 | 读 0 | 读 1 |
|---|---|---|
| A | 1 R B | 1 R E |
| B | 1 L C | 0 R A |
| C | 0 R D | 1 L B |
| D | **停机（未定义）** | 1 R C |
| E | 1 L F | 1 R E |
| F | 0 L B | 0 L E |

---

## 1. 归约声明（定理）

### 1.1 锚点构形

对整数 a ≥ 0, b ≥ 2，定义**锚点构形** f(a,b)：

> 纸带为 `0^∞ (10)^a 1^b 0^∞`（即 a 个 "10" 串后接 b 个 1，其余全 0），
> 图灵机处于状态 **D**，磁头位于 1^b 块的**第一个 1** 上。

等价的 A 参数化：A(a+1, b−1)（wiki 的 dyuan01 形式；A(a,b) = `0^∞ 1 0^a 1^b 0^∞`，头在 E、位于块右侧第一个空格——**注意**：A 形的 E-构形单独不构成自足不变族，见 §3 的反例实验；真正的不变族是锚点态）。

### 1.2 归纳步定理（f-形式）

从锚点构形 f(a,b)（b ≥ 2）出发：

- 若 **b < a+2**：机器**不停机**地到达下一个锚点 **f(a−b+1, 4b−1)**；
- 若 **b > a+2**：机器**不停机**地到达下一个锚点 **f(2a+2, b−a−1)**；
- 若 **b = a+2**：机器**停机**（触发 D 读 0）。

A 参数化下即：A(a,b)（a,b ≥ 1）：a>b → A(a−b, 4b+2)；a<b → A(2a+1, b−a)；a=b → 停机。

### 1.3 起点与主定理

- 空白带运行 **5 步**后到达锚点 **f(0,3)**（= A(1,2)）。
- **主定理**：BMO 1 在空白带上停机 ⟺ f-轨道 (0,3) → … 在某步到达某个 f(a, a+2)（A 参数：某步 a=b）。

轨道封闭性：从 b ≥ 2 出发，两分支的像分别有 b′ = 4b−1 ≥ 7 与 b′ = b−a−1 ≥ 2（后者因 b > a+2 ⟹ b′ ≥ 2），或恰在 b = a+2 停机。因此轨道永不进入 b=1 的退化域。

### 1.4 边界例外（已刻画，不影响主定理）

f(a,1)（任意 a ≥ 0，即 A 参数 b=0 的退化域）：锚点构形下机器 **2 步内停机**（D 读 1 → 1RC → C 读 0 → 0RD → D 读 0 停机）。由于 §1.3 的封闭性，空白带轨道永不触及 b=1。

## 4. 由归约引出的停机问题（数学核心）

主定理把停机问题化为纯数论问题：

> **BMO1 停机 ⟺ 从 (1,2) 出发迭代 A(a,b) 映射（a>b → (a−b,4b+2)；a<b → (2a+1,b−a)）某步命中 a=b。**
