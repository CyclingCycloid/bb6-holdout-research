# M1 — `1RB1LA_0RC0RD_1LC1LA_1RE1RD_1LF0LA_---0LE`

Cubic Mess 家族（mxdys 台账行 736）。本战役第一台深挖机。

## 结果

- **条件定理**：M1 从空白带启动永不停机，条件于假设 M。
- **无条件部分**：停机构型 G(a=3) 结构性不可达（头部形式 a+1 = 2^j·奇≥3；支配引理保证 h≥82 一切比较裕度恒正）；一切轮类 ≤ 2000 的运行不停机（逐类穷尽）——按记录时刻表 ×4/级爬升律（实测至第 32 级）折算为 ≳ 2^(2^2000) 步。
- **障碍定理**：假设 M ≡ 自主映射 α↦α+Δα(ν₂(α+1)) 的记录时刻表无限延续（分段仿射迭代的轨道命中问题）；周期排除定理 + 必要精度定理证明其在本架构内不可有限闭合。研究域：广义 Collatz / 分段仿射迭代（Conway 1972 不可判定类；Kurtz–Simon 2007 独立性）。
- undecided 状态未改变。
