# cm2-cases.md — W1/W2 案例空间与分派支明细（cm2-nonthalt-zh.tex 的附录引用件）

逐案例的机器验证由 `attacks-cm2/casecheck-*.mjs` 承担（一行可跑，见 attack-cm2.md §11.5）。
本文件给出书面引理的完整前件/转移字/净效应与分派支的推导骨架。

## 1. 七条例程引理（W1）

记号：转移字一步 = (状态, 读符 → 写符, 移动, 转状态)。头起始位 h；"deposit" = B0 写入
[h+1] 的 1（多数情况下随即被 E1 擦除或成为留存存款）。

### S（冲刺）
- 前件：A@h，[h..h+k−1]=1（k≥1）。
- 字：(A,1→1,R,A) × k。
- 净效应：磁带不变，头 h+k。
- 案例空间（穷举）：k∈{1,2,3,7} × [h−1]∈{0,1} × [h+k]∈{0,1}（字只读块内 k 格）。
- casecheck-s.mjs：28 案例，224 断言 PASS。

### Lap（波浪）
- 前件：A@h，[h]=[h+1]=[h−1]=0，[h−2]=1。
- 字：(A,0→1,R,B) (B,0→1,L,C) (C,1→0,L,D) (D,0→0,L,E) (E,1→0,R,A)。
- 净效应：[h−2]:=0（左块右缘侵蚀）、[h+1]:=1（deposit）、[h] 还原 0、头 h−1；
  存款与剩余左块之间恰 3 个 0（"隔 3 格 0 洞"）。
- 案例空间：左块长 ℓ∈{1,2,3,7}（含 [h−3] 归属）× [h+2]∈{0,1}（deposit 已存在/否）。
- casecheck-lap.mjs：8 案例，168 断言 PASS。

### Fill（填充）
- 前件：A@h，[h]=[h+1]=[h−1]=[h−2]=0。
- 字：(A,0→1,R,B) (B,0→1,L,C) (C,1→0,L,D) (D,0→0,L,E) (E,0→1,R,E)³ (E,1→0,R,A)。
- 净效应：[h−2]:=[h−1]:=[h]:=1（恒 3 充填；[h−3]=1 时并入左块）、[h+1] 还原 0、头 h+2。
- 案例空间：[h−3]∈{0,1} × [h+2]∈{0,1}。
- casecheck-fill.mjs：4 案例，132 断言 PASS。

### Dance（净舞，干净支）
- 前件：A@h，[h]=[h+1]=0，[h−1]=1；y = 从 h−2 向左首个 1（存在），s=h−y≥2；
  [y−1]=[y−2]=1。
- 字：(A,0→1,R,B) (B,0→1,L,C) (C,1→0,L,D) (D,1→0,R,F) (F,0→0,L,F)^s (F,1→1,L,B)
  (B,1→0,R,C) (C,1→0,L,D) (D,0→0,L,E) (E,1→0,R,A)。
- 净效应：吃 {h−1}（前缀 D1）∪ [y−2..y]（B1/C1/E1）、deposit [h+1]:=1、头 y−1。
  s=2 时四格连续 [y−2..h−1]（"吃 4"）；s≥3 时 [h−1] 为孤岛单独吃。
- 案例空间：s∈{2,3,5} × 落块长 λ∈{3,4,7} × [h+2]∈{0,1}。
- casecheck-dance.mjs：18 案例，906 断言 PASS。

### DanceFill（填尾舞）
- 前件：同 Dance，但落块恰长 2（[y−1]=[y]=1，[y−2]=0）。
- 字：Dance 前缀同上至 (D,0→0,L,E)，后接 (E,0→1,R,E)^{s+3} (E,1→0,R,A)。
- 净效应：[y−2..h]:=1（回填落对、岛与全部零格）、[h+1]:=0、头 h+2；pop Δ=+s。
- 案例空间：s∈{2,3} × [y−3]∈{0,1} × [h+2]∈{0,1}。
- casecheck-dancefill.mjs：8 案例，552 断言 PASS。

### L1（窄洞舞）
- 前件：A@h，[h]=0，[h+1]=[h+2]=1（[h+2]=0 时 C 读 0 → H1 停机，属引理 H 不属本例程）。
- 字：(A,0→1,R,B) (B,1→0,R,C) (C,1→0,L,D) (D,0→0,L,E) (E,1→0,R,A)。
- 净效应：[h+1]:=[h+2]:=0（pop −2）、[h] 还原 0、头 h+1。
- 案例空间：岛长 λ∈{2,3,7} × [h−1]∈{0,1}。
- casecheck-l1.mjs：6 案例，126 断言 PASS。

### DBL（双舞 / B0-支循环）
- 前件：Dance 前件，且落块为孤岛（[y₀−1]=0）而 [y₀−2]=1；左侧有限结构
  1^{β₁} 0^{γ₁} 1^{β₂} …（βᵢ≥1, γᵢ≥1）。
- 轮规则（书面；动态格子上逐条执行）：
  1. B0：读 0@[y−1]，写 1，左行 → C；
  2. C@[y−2]：0 → 下一步 C 读 0，**H2 停机**（字终）；1 → C1（擦 [y−2]）→ D@[y−3]；
  3. D@[y−3]：1 → D1（擦 [y−3]）→ F-重扫（[y−2..y′+1] 全 0，y′=首个 ≤y−4 的 1）→
     F1 → 下一轮（落点每轮左移 ≥4）；0 → D0 → E@[y−4]：
     - 1 → E1（擦）→ A@[y−3]，终；
     - 0 → E0³ 回填 [y−4..y−2] + E1 擦本轮 B0 格 [y−1] → A@[y]，终。
  4. B1 尾（某轮落点 y′ 有 [y′−1]=1）：B1 C1 D0 后 E@[y′−2]：1 → E1 → A@[y′−1]，终；
     0 → E0 右填至最近的**历史 B0 格**（中间全 0）并 E1 擦之 → A，终（无历史 B0 格时
     即经典 DanceFill：填至 deposit [h+1]）。
- 净效应：每循环轮吃 [y−2]∪[y−3]、写 [y−1]（岛对左移生长）；终止轮按支如上。
- 案例空间：(β,γ) 序列，β∈{1,2,3,5}, γ∈{1,2}, 深度 ≤3（584 结构；扫描逃逸按假设排除，
  实测 0 例——深锚保证落点存在）。
- casecheck-dbl.mjs：470 支到 A + 114 支 H2 停机，43424 断言 PASS。
