## 13. 追加修复轮：对角不变量与 CRT 剩余类（两牌战果）

### 13.1 牌一：对角不变量 Q = L − 3R（部分成立）

* **扫掠不变性（∎ 初等代数）**：扫掠 (L,M,R)→(L+3,M−4,R+1) 下 Q′ = (L+3)−3(R+1) = Q。
  Q 是每条扫掠的精确守恒量——**"距离 3 擦过"的结构解释**：一步扫掠同时移动 L 和 R
  （ΔL=+3, ΔR=+1），不可能只动 L 不动 R；轨道 (M1,L48,R20) 与致死格 (M1,L51,R20)
  不同 Q（Q=−12 vs −9），一步后到 (L51,R23)，Q 不变，永不落在 (L51,R20)。
* **重启 Q-映射**：M4 → **Q′ = 0 恒等（∎ 结构性）**：M4-重启 (3, pop−1, 1) 后
  L = 3(k+1), R = k+1 ⟹ 整条 M4-生扫掠上 **L = 3R 精确成立**；M3 → **Q′ = Q+20（∎）**；
  M2/M1 → 路线依赖（与 L₀′ 同源障碍）。
* **轨道 vs 致死库**：127,694 个标记 × 193 格——**Q-碰撞 0**。但按 (M,R) 类分层后，
  分离的本质仍是 R-流避让（M3 终点 R ∉ {1,7}），Q 不蕴含它。mod 3 护城河 = Q ≡ 0
  (mod 3) 的线性伪装（Q = L−3R ≡ L ≡ 0）。
* **裁决**：Q 是真实的轨迹不变量（新工具），**单独不闭合**。

### 13.2 牌二：CRT 剩余类封闭（否定结果，如实记录）

* 首轮扫描有 bug（致死库无 Q 字段 → NaN 恒假）已修正；**修正后**：
  (M 精确, R mod m₂, Q mod m₃) 扫描 m₂,m₃ ∈ {3..128 素数幂}、乘积 ≤ 10⁴：
  **3×3 即与全部 193 格碰撞**；唯一分离对 (128, 64)——但轨道 127k 标记在
  ~10⁶ 格状态空间的期望碰撞 ≈ 24，零碰撞与采样稀疏一致，**非结构分离**（无证明价值）。
* **剩余类层面的动力学**：中扫掠步 (R+1, Q) 与 M4/M3 重启（pop = Q+4R+M 全由剩余类
  决定）在剩余类上良定义 ✓；**M2/M1 重启的 L₀′ 路线依赖值而非剩余类** ✗——
  剩余类封闭在 M2/M1 处再度撞墙（与 §10–11 同一堵墙）。
* **L6 级否定结论**：不存在 ≤10⁴ 乘积的 (R,Q) 分离模数对（除采样假象）；
  剩余类论证对此系统**结构性失效**，失效点 = M2/M1 重启路线。

### 13.3 墙的终局定性（三轮修复后的合成判决）

三种闭合技术全部试尽、全部确定性失败于**同一障碍**：
1. 路线常数（§11）：M2/M1 重启常数非全称排除（合成停机反例）；
2. 剩余类（§13.2）：M2/M1 重启不剩余类确定；
3. 不变量（§13.1）：Q 守恒但不蕴含 R-流避让。
⟹ cm2 非停机证明的剩余核心 = **分段仿射扫掠-重启系统的轨迹避让命题**
（R-流永避 {8·4ⁿ−1} 谱系 + M2/M1 路线永避其致死前像），与 Collatz 猜想同型。
经验界：3×10^10 步零命中（含 127,694 尾空标记零 Q-碰撞、零剩余类例外）。

**终版台账**：A 级（引擎、致死集刻画）；A−（扫掠定理、Ψ、M4-入口 ∎、mod 3 护城河、
Q-不变量及其两个 ∎ 重启公式）；B（3e10 轨迹避让经验）；**C（无条件证明：
Collatz 型轨迹命题——墙已证硬：三种标准技术在此系统上全部失效，失效点已定位）**。
