## 结果（每台独立）

- **条件定理**：各台永不停机，条件于危险五格图案 `1,0,1,0,1` 的头远规避。
- **无条件部分**：停机判据 ×4——分别枚举、分别穷尽（casecheck 204,800 构型零反例）；孤岛不变量（孤岛存在 ⟹ 摧毁波同位，39 断言 + 轨道 892 例全同位）；统一 lap 文法簿记（四台各自逐格验证，约 78 万锚点）；guard 2×10^11 步 ×4 零威胁。
- **四台对应关系**：lap 文法统一（每台各自验证）；era 序列 562 对常量偏移零错位（深扫前缀上的观测）；末构型仅冻结骨架逐位相同（工作三元组差 ±100）。未建立同构定理；装配逐台独立。
- **障碍**：键图局部抽象路线判死（|K*| 每半径 ×3.1 发散，复跑逐位复现）。研究域：与 cm2/M1 残余同型的轨迹避让（类比归类，未逐台形式重述）。
