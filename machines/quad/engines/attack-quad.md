## 2. 例程文法（lap 波）与逐格账本

cm16 一个 lap（A0 事件到下一 A0 事件，Δt≈2·reservoir+O(1)，era-A 实测 45,737 步 @1e9）：

```
A0 填左缝左格 → B0 → C1 → D1 擦 reservoir 左缘 → A1 擦次格 → E0 → D0 填 → F0 填
→ B1 右扫穿 reservoir → B0 → C0 填右缝右格 → C0 → C1 → D1 → A1 擦 reservoir 右缘
→ E1 左扫穿 reservoir → E0 → D1 擦左缘余格 → A0（下一 lap）
```

**逐格净效应（cell-diff 精确验证，每 lap 恰 4 格翻转）**：
`x+1（左缝左格并入左接收器）、reservoir 左右缘各 −1、z+1（右缝右格并入右接收器）；
两条 0² 缝位置各移 1 格、宽度不变`。

即 **统一 era 映射（lap 级）**：
> 工作三元组 (x | 0² | R | 0² | z)：每 lap x+1，R−2，z+1；lap 步数 ≈ 2R。

验证：`quad eras` 差分检测器要求每对相邻 pivot 事件严格满足 (+1,−2,+1) 才归类 era 事件
——四台分别 **784,848 / 776,621 / 776,451 / 852,633 个 lap 锚点**（≥500×10³/台，任务指标超验）。

## 5. 停机风险的经验刻画：孤岛不变量（候选，精化版）

cm16 停机图案的几何必要条件 = B-冲刺落点右侧存在 **(0¹,1¹,0¹) 孤岛**（1-格块两侧缝恰 1）。
关键分析（lap 波内序推演）：

* **孤岛只以瞬态存在**：era 末 reservoir=1（奇 R₀）时，右波 C0 填 g2' 后出现
  `x'|0¹(g2)|1(s)|0¹(g1')|z'` ——孤岛成形；但**同一道波在 sprint 之前将其摧毁**：
  D1 擦 g1'、A1 擦 s、E0/D0/F0 重填后 B1 才起扫。即孤岛的创造者与摧毁者
  = 同一道经过波，创造与摧毁之间无 sprint 落点。
* 两侧缝**从不同半 lap 收窄**：左缝收窄（A0 填 g1）发生在 lap 前半、右缝收窄
  （C0 填 g2'）在后半，两次收窄之间 reservoir 两侧总有一侧 ≥0²——除上述
  R=1 瞬态外，(0¹,1¹,0¹) 几何不可达。
* 实测：20,787 个 pivot 相位构型（0→1.4e9）：孤岛 **0 次**（瞬态只存在于
  pivot 之间，与理论一致——pivot 相位所有缝 =0²）；过渡期 lone-1 全部带 0² 邻缝
  或处于带端（`…4,1|0⁴`、`0²|1|0²` 型）✓。
* **casecheck-island.mjs（VERDICT ALL PASS，39 断言）**：本节已升级为机器验证——
  (i) 标准 lap 转移字**逐字验证**（A0 B0 C1 D1 A1 E0 D0 F0 | B1^(R−2) B0 C0² C1 D1 A1 |
  E1^(R−1) E0 D1 A0，恰 2R+14 步；R∈{13,20,40} 参数格）且全 lap 孤岛审计：瞬态孤岛
  每 lap 恰两段（左波 A1..F0、右波窗口），**头与孤岛距离 ≤1**（摧毁波在场），0 个
  头远孤岛；(ii) 排空特例 R∈{1,2,3,4}：波离脚本、但**停机前提 0 命中**、全部孤岛段
  单步存活、段内无 sprint、死于下一 sprint 前；(iii) 真实轨道 2e7 步审计：892 个
  孤岛步全部头距 ≤1、0 个头远、停机前提 0 命中。
* 修正记录（诚实条款产出）：会话内初版断言"孤岛仅 R=1 时存在"**被 casecheck 否证**

  错位）已修复并写入检测器。断言语义：孤岛不变量 = "**孤岛存在 ⟹ 摧毁波在同位**"，

## 14. 终封轮：key-graph 阶梯实验（COV 判定）与终局台账

### 14.1 方法

键 =（状态，头 ±r 窗），宇宙 6×2^(2r+1)（有限）。单步后继由 [h−r−1, h+r+1] 完全决定：
枚举 2 个自由边界格（4 补全），跑裸转移得后继键——对一步归纳**Sound 且穷尽**。
封闭 K*_r = 从空白初键（A，全 0 窗）BFS 全补全后继至不动点（有限宇宙必收敛）。
危险键 D_r = 窗口使下一步即执行进洞转移的键（= casecheck-halt 的充要前提之键化）。
判定：K*_r ∩ D_r = ∅ ⟹ 归纳（key₀∈K*_r、K*_r 全补全封闭、停机需 D_r）⟹ **无条件非停机**。

## 15. 时代层对应定理（bisimulation 实验）：排空层恒等，churn 层与停机谓词不对应

日期：2026-10-12。校验器：`quad-equiv.mjs`（一行复跑 `node quad-equiv.mjs`）。
问题：四台的"同一时代级程序"（§4）究竟是**映射级恒等**（bisimulation，可归纳传递），
还是**轨迹级现象**（对齐不可传递）？本节以有限表比较裁决。

### 15.1 定义（抽象状态空间 S 与典范实现 ρ_M）

* **标记态（S 的元素）**：s = (b, pos)，b = (b₀..b_{n₀−1}) 全带 1-块长向量，pos = 工作三元组
  (L,R,Z) = (b_pos, b_pos+1, b_pos+2) 的位置。键 (pos,n₀) 即 §5b 键；环境 = b 中其余块。
* **典范实现 ρ_M(s)**（四台的机器特定几何，**经验零违例**：早期+中期 pivot 轨迹
  5823 个 era 事件逐个核验）：
  * 带构型：块间一律 0¹ 分隔，**唯三元组内部除外**——gap 宽度为机器常数：
    cm16 (2,2)、cm26 (1,1)、cm51 (1,2)、cm52 (1,1)（5823/5823）；
  * 头+态 = 该机的 pivot 事件落在三元组缝上：**cm16 = A0 于 L|R 缝首格**（离 L|R 缝首
    偏移 0），**cm26 = D0、cm51 = A0、cm52 = C0 于 R|Z 缝首格**（偏移 R+1）（5823/5823）；
    pos=0 ⟺ 左缘 virgin、pos+2=n₀−1 ⟺ 右缘（后者仅 cm52 的 11 个额外键出现）。
* **时代步映射 F_M(s)**：从 ρ_M(s) 起跑——era A = 锚点所属时代的剩余 lap 至排空，
  继而 churn，era B 开启——输出 {A.key, A.open, A.close(eL,eR,eZ), A.laps, B.key,
  B.open, halt, timeout}。检测器与 quad.c `eras` 模式同构（S0 对拍：四台前 14 个 era
  记录逐字段吻合，含 C 引擎步号 +1 约定）。
* **忠实性（S1，全部 PASS）**：5 个真实锚点（4 台深度 ~5e6 对应时代 + cm16 深度 120）：
  规范形核验（gaps/环境缝/偏移规则）+ 抽象→重构→重放 = 真实重放（记录恒等）+ 轨道
  ground truth 吻合；JS 引擎 halts 与 quad6.exe `from` 模式抽检一致（HALT@2、HALT@192）。
  排空代数：全部 166,980 个真实 era（41,286+33,112+33,112+59,470）满足精确恒等式
  eL = L₀+(R₀−eR)/2、eZ = Z₀+(R₀−eR)/2，eR ∈ 终态剩余 {1,2}（cm16/51/52）或 {2,3}（cm26）。

### 15.2 实验（逐键表比较 + 真实态反事实重放）

### 15.3 结果与定理（A−，有限表 + 轨道全量）

**定理（时代层对应，正部分）**。在共享 lap 域 R≥4 上，四台的**时代内排空映射恒等**
（每 pivot 间隔 (+1,−2,+1)，圈数与 eL/eR/eZ 逐字段相同），唯一例外是 cm26 的**显式
奇 R 修正** σ：奇 R 输入时 cm26 少跑一圈（laps−1）且 eR = 基准+2、eL/eZ = 基准−1
（其终态剩余 {2,3} vs 其余三台 {1,2}）。证据：(i) 轨道全量 166,980 era 排空恒等式
精确；(ii) S2 非排空行 90/90 恒等（72 偶 R 原始恒等 + 18 奇 R 经 σ 修正恒等）；
(iii) S2B 真实态重放 R≥4 行 30/30 恒等（含 cm26 σ）。R=3 输入为结构分歧点：
cm26 直接收步（3 是其奇终态），cm16/51/52 再跑一圈到 1。cm51、cm52 的排空层与
cm16 **完全恒等**（含 R=3）。∎（表级 + 轨道全量；A−）

**推论（可传递部分）**：从对应开锚（相同块向量）出发、直到第一个 churn 段之前，
三/四台的 era 演进逐圈对应（对应是抽象层的：每圈 pivot 间隔的步长各异——实测
cm16 2R+13、cm26 2R+1、cm51/cm52 2R+9（R=圈首储量；§5c 的 2R+14 为词长/符号数
约定）；562 大 era 对齐中 cm26 的 L 偏 +1 即 σ 的累积极限，cm52 的 R₀+2 见下）。

**否定结果（对应关系的真实边界，如实记录）**：
1. **churn/重播种层不对应**：S2 全清洁行 eraB（下一时代开参数）四台恒等 **0/110**，
   S2B 真实态 **0/40**。分级：cm51 最远——churn 后键必变（110/110、40/40 落到不同键，
   值可无界偏离，实例 (−991,−598,0)）；cm26 键保 95/110（合成）、值偏移非零
   （主型 (1,−1,0)、(0,1,−1)）；cm52 键保 74/110、值偏移集中（主型 (0,1,0) = R₀+1，
   72/110——与 §4 轨迹偏移 (0,2) 同源但非恒定）。**§4 的 562 大 era 常量偏移对齐
   是轨迹现象，不是映射恒等的推论**（重测修正：m26↔m16 偏移为 (ΔL,ΔR) ∈ {(1,0):556,
   (0,2):6}，m51↔m16 ∈ {(1,−1):556, (0,1):6}，m52↔m16 恒 (0,2)，各 6 个翻转点）。
2. **F_M 均为部分映射，且停机谓词不共轭**：S2 结局混合行 280/390——同一抽象态一台
   halt 另一台正常（如键 (0,4) 边界组：cm16 clean、cm26 halt@2、cm51 halt@102、
   cm52 clean；各台致死区互不相同：cm26 全 78 个 R=1 行 halt，cm16 于 R=13 组 60/78
   halt，cm51 于 R=8 组 61/78 halt）。S2B：18/60 真实态行有台 halt（13 个排空输入态 +
   5 个中值态）；**决定性反例**：cm26 自己轨道的第一个时代开锚 (5,4,2,2)@pos0
   （步 134）对 cm26 正常演进，而 cm16 halt@170、cm51 halt@990、cm52 halt@6294。
   停机结局不是 S 上的函数 ⟹ **"cm16 停机 ⟺ cm26 停机 ⟺ cm51 停机"不可经时代层
   对应传递；cm52 亦按其自身判据单独陈述**——时代动力学（排空层）对应、停机谓词
   不对应，非停机证明必须逐台装配（§8 立场自此有表级证据）。
3. **σ54 不存在**：任务假设的 cm52 显式修正（偏移/键映射 89↔78）在映射级不成立
   （eraB 恒等 0 行，值偏移非恒定）；cm52 的 89 键 = 共享 78 + 11 个右缘键的真包含，
   S3：从 11 个额外键出发 53 次有 42 次回到共享键（2 次直接 halt）——包含关系不构成

**对台账的含义**：跨机同构（§4，A−）细化后为——lap/排空文法层恒等（可传递，本节
定理），churn 层与停机层不传递。四机证明共享的引理库 = 排空层（+孤岛不变量词表），
