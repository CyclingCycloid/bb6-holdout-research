## 四、价值排名（无条件闭合概率优先）

评分要素：① 构型/时代规则性（相位演算可行性）② 锚点映射接近闭式的程度 ③ 观测 ν₂ 是否被压制（记录事件不承重的正面信号）④ 与既有工具（phase1.mjs / sym4.mjs / ladder.mjs / 模类模板）的适配度 ⑤ 一次分析覆盖的机器数。

### #1 cm2 — `1RB1RA1LC0RC---0LD0LE0RF1RE0RA0LF1LB`
- **行为**：α=0.322（立方族最慢之一），span 2359 / pop 2352 / runs 5 @10^9 —— **CM 中末构型最稀疏**（与 M1 并列 5 runs）。洞在 D0。
- **锚点初查（实测）**：D0 事件密度高（~1.66×10^8 @10^9），事件表呈**严格时代结构**：宽度序列 6→9→11→14→12→17→19→17→20→18→21→…（+3/+2 增长段与 −2 收缩段交替，上漂）；每时代内 (a,g,b) 三 run、**a+b 守恒、headrel 线性递减（纯扫描）**，时代边界做质量跳变。
- **记录事件风险**：未见浅层 ν₂ 爆发；时代递推是加法型（非 ×2+1 一线式），ν₂ 深度由嵌套计数器联合决定——**待定，未见 M1 型时刻表迹象**。
- **攻击角度**：D0 相位演算：扫描段=平凡引理；时代转移=2-计数器线性系统 → 模类阶梯（M=宽度极大值序列）。
- **无条件闭合路线图**：L0 事件表（已完成，`temp/cm2-ev.txt`）→ L1 时代转移闭式（宽度极大值 M_k 的递推；预估 1 个会话）→ L2 相位引擎（phase1.mjs 模板改造，1 会话）→ L3 模类轮律（sym4.mjs 逐 h 符号化；模 k 预计 2–6，1–2 会话）→ L4 覆盖证书（ladder.mjs 延长 + 主定理装配，1 会话）。
- **预估难度**：中高。**排名理由：规则性最高 + 构型最简 + 密度最高。**

### #2 cm57 — `1RB1RA1RC1LB1LD0RA1LA0LE---0LF0RC0LB`
- **行为**：α=0.330，span 3422，runs 9；双相轨道（A1 49.7% / B1 49.7%）。洞在 F0。
- **锚点初查**：4-block **对称族**（blocks a,b,c,d 满足 a↔c 镜像，gaps 恒 1,3,2）；动力学=质量守恒拉伸段 + 偶发 ×2 事件（1+6+1+8 → 翻倍），近精确映射误差 3/17（`w1=1/2 v0, w2=15/2 v0` 型——半整系数，说明存在 parity 分支）。
- **记录事件风险**：**观测 ν₂(1-block+c) ≤ 4 且记录偏早期**（r9 类 4@3/13、r7 类 4@5/12、r5 类 4@6/13）——正面信号（窗口内被压制）。
- **攻击角度**：对称性=代数抓手（镜像构型归并相位状态数减半）；模 2 分支先行（半整系数来源），再引入模 3/模 6。
- **路线图**：L1 镜像归并 + ×2 事件刻画 → L2 相位引擎 → L3 奇偶-类轮律 → L4 证书。每层 1 会话，共 ~4。
- **预估难度**：中。对称性是 M1 没有的优势。

### #3 cm29 + cm50（孪生对）— `1RB1LA1LC0RE---0LD1LA0LF1RA1RE1LA0LB` / `1RB1LA1LC0RE---0LD1RE0LF1RA1RE1LA0LB`
- **行为**：α=0.340/0.345，span 6721/6579，runs 15/15；双相（E1+A1 各 ~49.5%）；D0 事件仅 2/3 次 @10^9（D0 非相位变量）。洞在 C0（两台同位，仅 D0 转移不同：1LA vs 1RE）。

- **路线图**：同 #1 模板，L1 起需并排双机验证（每层 ×1.2 工作量），共 ~4.5 会话。
- **预估难度**：中。

### #4 qm30 — `1RB1LC1LC0RD0LE1LA0RF1RA1RD0LA---0RB`
- **行为**：α=0.502（平方族），span 20218 / pop 20214 / **runs 3**（`1^9253 0^2 1^6330`：2-block + 恒宽 2 缝）。洞在 F0。D0 事件 26947（中等密度）。
- **锚点初查**：r5/d6/g1,2 主族 359 事件（D0）；自动拟合曾给出 9 对上的"精确"映射（`w0=3/2 v1, w2=9v1,…`）但**欠定（<3d）已按过拟合风险拒判**——需 1500+ 事件重验。构型形态是全部候选中最简单的（两块一缝）。
- **记录事件风险**：待深查（首次 FORCE 分析的窗口不足）。
- **攻击角度**：二次时间 + 2-计数器：锚点参数 n（两块长度）的映射若为 n' = r·n ± O(1) 型，则轮律只有 ~log n 类——**若类集合有限即逐类穷尽闭死（最高价值形态）**。
- **路线图**：L1 大窗口事件表（CAP 5×10^9，MAXREC 1500，0.5 会话）→ L2 严格 era 闭式 → L3 类计数（若 ≤常数类：直接穷尽证书，跳过轮律）→ L4 装配。~3 会话。
- **预估难度**：中高（成败取决于 era 映射是否一线式）。

### #5 qm6 — `1RB0RF1RC1RF1LD0LE---1LC1RA1LE1LC1RB`
- **行为**：α=0.519，span 26681 / pop 26679 / runs 3（`1^11055 0^1 1^12011`）。洞在 D0。转移用量 E1 50% / F1 25% / B1 25%——三事件规则轨道。
- **锚点初查**：D1 事件主族 571 事件呈**线性斜坡**：v0 += 3、v2 −= 2、headrel += 1（逐事件），斜坡间跳变——**这就是 M1 型 mod-类结构**（gcd(3,2)=1 ⟹ 斜坡覆盖全部剩余类，ν₂(v2+c) 沿斜坡代数上无界）。
- **记录事件风险**：**高**——实测 ν₂ max 8@323/571（56% 处）与 r1 类 6@28/29（97% 处）：记录持续推迟出现，与 M1 时刻表同型。
- **攻击角度**：M1 的 mod-6 模板直接适配（斜坡=轮内 Ψ-梯）。**但**：这意味着它大概率落入"记录时刻表"困难——除非其跳变规则能把类深度压平（ν₂(n+c) ≤ 常数），否则只能得到 M 型条件结果。
- **路线图**：L1 斜坡-跳变闭式 → L2 模 6/模 12 相位引擎（直接复用 M1 引擎改造）→ L3 判定类深度是否被压制 → L4a 若压制：逐类穷尽证书；L4b 若不压制：M 型条件闭合（同 M1 形态）。~3 会话到分叉点。
- **预估难度**：高（M1 同款）。**排名靠后正是因记录事件大概率承重。**
